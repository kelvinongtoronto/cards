# The `cards` Repo

This repository contains various python apps demos using a pack of playing cards

## `pynocard.py`

`pynocard.py` is a port of [Dino Cards by Dynotech software](https://archive.org/details/win3_DCARDS11) written using pygame. It also implements the game modes not available in the shareware version

`dynoport.py` is a command-line implementation of that game.

## Card demos

The repo contains pygame demos, displaying a deck of cards in various styles. Clicking on a card flips it over, and a drag-and-drop action swaps two cards.
